# CSS Interview Questions

## 1. What is CSS?
CSS styles HTML elements.

## 2. What is the Box Model?
- Content
- Padding
- Border
- Margin

## 3. Difference between Flexbox and Grid?
Flexbox → one dimension

Grid → two dimensions

## 4. What is specificity?

Rules used to decide which CSS style is applied.

## 5. What is responsive design?

Making websites work on different screen sizes.
