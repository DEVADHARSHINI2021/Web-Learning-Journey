# HTML Interview Questions

## 1. What is HTML?
HTML (HyperText Markup Language) is used to structure web pages.

## 2. Difference between id and class?
- id → unique
- class → reusable

## 3. What are semantic tags?
Examples:
- header
- nav
- section
- article
- footer

## 4. What is the purpose of the alt attribute?
Provides alternative text for images.

## 5. Difference between div and span?
- div → block element
- span → inline element
