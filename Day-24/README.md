# Day 24 - Word Counter

## Features
- Count total words
- Count total characters
- Count characters excluding spaces
- Updates instantly while typing

## Concepts Learned
- DOM Manipulation
- Event Listeners
- String Methods
- Regular Expressions
- JavaScript Arrays

## Technologies Used
- HTML
- CSS
- JavaScript

## Preview
Type or paste text into the box, and the app will automatically display the number of words and characters in real time.
