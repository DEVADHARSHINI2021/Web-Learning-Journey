# Day 23 - Palindrome Checker

## 📌 Project Overview
A simple web application that checks whether the entered word or sentence is a palindrome. It ignores spaces, punctuation, and letter case before performing the check.

## 🚀 Features
- Check if a word or sentence is a palindrome
- Ignores spaces and special characters
- Case-insensitive comparison
- Instant result display
- Simple and responsive interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 📚 Concepts Practiced
- Event Listeners
- DOM Manipulation
- String Methods
- Arrays (`split()`, `reverse()`, `join()`)
- Regular Expressions
- Conditional Statements

## ▶️ How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter a word or sentence.
4. Click **Check** to see whether it is a palindrome.

## 📷 Example
Input:
```
madam
```

Output:
```
✅ It is a Palindrome!
```
