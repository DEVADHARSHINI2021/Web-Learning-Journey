# 📘 HTML Cheat Sheet

A beginner-friendly HTML reference containing the most commonly used tags and concepts.

---

# What is HTML?

HTML (HyperText Markup Language) is the standard language used to create web pages.

HTML describes the structure of a webpage using elements called **tags**.

---

# Basic HTML Structure

```html
<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>

</body>
</html>
```

# Best Practices

- Use semantic HTML.
- Always include the `alt` attribute for images.
- Keep code properly indented.
- Use meaningful file names.
- Close all tags correctly.
- Validate your HTML.
- Avoid inline styles whenever possible.
